Description

Metaclass was developed as an improved alternative for our high school's pre-existing website made with google sites. it was complicated, hard to navigate and had a lot of unnecessary tabs and empty pages. The organization of the site was made by teachers which made it confusing because of the lack of communication. Metaclass was designed to be simple, easy to navigate and have only the necessary information and tabs. It also came with innovative improvements such as a calendar, organizable class pages, class and school-wise announcements, fast navigation, localstorage based short term memory to ease picking up where you left off, and much more.

Technical Information

  • Language(s): TypeScript, JavaScript, CSS
  • Framework(s): React (TSX)
  • Database(s): Firebase - Cloud Firestore & Storage
  • Hosting: Firebase
  Other:
  • Authentication - Firebase Email & Password, Google OAuth (For GAPI token acquisition)
  • APIs - Google Drive Picker
